## 🎯 Project Overview
This application serves as a modern web-based portfolio built with **ASP.NET Core MVC (C#)**. It organizes 21 academic and personal GitHub repositories into a responsive UI with structured data models, cookie authentication, and an in-memory comment system.

---

## ✨ Key Features
- **Interactive Table of Contents:** Categorized navigation for quick filtering across all 21 projects.
- **Project Detail Pages:** Dedicated view for each project displaying comprehensive descriptions, metadata, and direct GitHub links.
- **Dynamic Comment Section:** Allows users to post feedback and comments per project.
- **Hardcoded Cookie Authentication:** Secure login mechanism using predefined credentials documented above.
- **Privacy Policy Page:** Dedicated route handling data safety and academic presentation details.

---

## 🛠 Architecture & Technologies
- **Framework:** ASP.NET Core MVC
- **Language:** C#
- **Frontend:** HTML5, Razor Views, Bootstrap 5
- **Authentication:** Cookie-based Authentication (`ClaimsPrincipal`)
- **Data Management:** Static in-memory data store (`PortfolioData.cs`)
